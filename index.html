Understanding CSS Color Variables CSS variables make it easier to change website colors. Instead of typing the same color code repeatedly, you can give the color a name. ### Step 1: Open style.css Near the top of the file, add: ```css :root { --background-color: #0f172a; --card-color: #1e293b; --accent-color: #38bdf8; --text-color: #ffffff; } ``` ### Step 2: Understand the Colors - `--background-color`: Dark navy background - `--card-color`: Background color for cards - `--accent-color`: Bright blue accent color - `--text-color`: White text ### Step 3: Use the Variables Example: ```css body { background-color: var(--background-color); color: var(--text-color); } ``` Another example: ```css .project-card { background-color: var(--card-color); } ``` The `var()` function tells CSS to use the stored color. If you change `--accent-color`, every CSS rule using that variable will update. Important: Existing color values must be replaced with `var()` for the variables to take effect. --- ## 5.
